## 🎭 ANIMATION STATES

### Page Load Animation
```
Cards slide up with fade-in effect:
0ms:   Opacity: 0%, Translate: Y=20px
300ms: Opacity: 100%, Translate: Y=0px
```

### Dialog Open Animation
```
Dialog appears with scale-in effect:
0ms:   Scale: 0.95, Opacity: 0%
150ms: Scale: 1.0, Opacity: 100%
```

### Button Hover States
```
Default: Background color normal
Hover:   Background darker, shadow appears
Active:  Background darker, slightly smaller scale
```
