## 💡 Usage Patterns

### Copy-Paste Ready Patterns

#### Gradient Header
```tsx
className="bg-gradient-to-r from-blue-50 to-indigo-50 dark:from-slate-800 dark:to-slate-900 p-6 rounded-t-lg border-b border-blue-200"
```

#### Animated Card
```tsx
initial={{ opacity: 0, x: -20 }} 
animate={{ opacity: 1, x: 0 }} 
transition={{ delay: index * 0.05 }}
```

#### Info Box with Icons
```tsx
className="p-4 bg-gradient-to-r from-blue-50 to-indigo-50 border-l-4 border-l-blue-600 rounded-r-lg"
```
